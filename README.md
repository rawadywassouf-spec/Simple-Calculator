
# Simple Calculator

أول مشروع لي في البرمجة باستخدام بايثون.  
آلة حاسبة بسيطة تدعم:

- جمع (+)
- طرح (-)
- ضرب (*)
- قسمة (/)
- باقي القسمة (%)
- جذر تربيعي (√)

## كيفية الاستخدام
1. شغّل البرنامج.
2. اختر رقم العملية.
3. أدخل الأرقام.
4. شوف النتيجة.

## الأدوات المستخدمة
- Python 3
- math library
